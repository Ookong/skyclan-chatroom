## 一、概念：数据也有"种族"（5 分钟）

W01 埋过一颗雷：input 收到的是话，要算数先 int。今天正式排雷——Python 眼里数据分**类型（type）**，类型不同，待遇天差地别。

本课三大主角：

| 类型 | 英文名 | 长相 | 例子 |
|---|---|---|---|
| 整数 | int | 没小数点、没引号 | `2026`、`11`、`-3` |
| 浮点数 | float | 带小数点 | `3.14`、`39.9`、`0.5` |
| 字符串 | str | 引号包住 | `"2026"`、`"喵"`、`"火心"` |

核心区别一句话：**"2026" 是写在纸上的字，2026 是能拿来算的数。**

猫武士式理解：喊"火心"这个名字，和火心真实扑向敌人的战斗力，是两码事。名字（字符串）不能加 1，战力（数字）可以比大小。

怎么选：数个数用 int，带小数的量用 float，一切话用 str。

## 二、type()：类型透视镜（5 分钟）

分不清时用 `type()` 照一照。新建 `types.py`，亲手敲：

```python
print(type(2026))
print(type("2026"))
print(type(3.14))
print(type("3.14"))
```

输出（尖括号里的英文就是类型名）：

```text
<class 'int'>
<class 'str'>
<class 'float'>
<class 'str'>
```

第四行最阴险：**带引号的小数也是字符串**。

再给 W01 的大坑补个铁证：

```python
age = input("How old are you? ")
print(type(age))
```

不管输入 11 还是 abc，`type(age)` 都是 `str`——**input 收到的一切都是字符串**。

## 三、转换三兄弟：int() / float() / str()（10 分钟）

类型不是终身制，可以转换：

```python
print(int("2026") + 1)     # 2027: text "2026" becomes a number
print(float("3.5") * 2)    # 7.0: text "3.5" becomes a decimal
print(str(11) + " years old")   # number 11 becomes text, now it can join
```

### 逐字拆解 `int("2026")`

| 部件 | 作用 |
|---|---|
| `int` | 转换命令：目标是整数 |
| `(` `)` | 要转的东西放括号里 |
| `"2026"` | 原料：字符串版的 2026 |

结果得到**真正的整数** 2026，能参加一切数学运算。

最常用的组合拳（W01 见过第一个）：

```python
age = int(input("How old are you? "))
price = float(input("Price in yuan? "))
```

先由 input 收话，再转成数装盒：整数用 int，可能带小数用 float。

## 四、数字运算符全家福（8 分钟）

`+ - * /` 是老朋友，介绍三位新面孔：

| 运算 | 式子 | 结果 | 说明 |
|---|---|---|---|
| 真除法 | `7 / 2` | `3.5` | 结果**总是 float**，`8 / 2` 也得 `4.0` |
| 整除 | `7 // 2` | `3` | 扔掉小数部分 |
| 余数 | `7 % 2` | `1` | 7 里装满 3 个 2 之后剩下的 |
| 乘方 | `2 ** 10` | `1024` | 2 自乘 10 次 |

`//` 和 `%` 现在冷门，W03 判奇偶、W04 画图时天天用。

冷知识：`int(3.9)` 得 `3`——**直接砍尾，不四舍五入**。

## 五、⚠️ 转换翻车现场（8 分钟）

每个坑都值得亲手踩一次，读报错最后一行：

1. **int 不收带小数点的字符串**：`int("3.5")` → `ValueError`。字符串里的小数要找 float：`float("3.5")` ✅
2. **int 不收不是数的字**：`int("你好")` → `ValueError`（这串字变不成整数）
3. **字符串乘法是复读机**：`"10" * 3` 得 `101010`，不是 30！字符串遇到 `+` 是拼接、遇到 `*` 是重复，只有真数字才做数学
4. **该用 float 的地方用了 int**：问价格写成 `int(input(...))`，输入 12.5 → 当场 ValueError。规则一句话：答案可能带小数的问题，用 float 收

彩蛋（不是你的错）：Shell 里算 `0.1 + 0.2`，看看得多少——电脑的小数世界会多出一串零头。别慌，W02-L03 的 `:.2f` 一招治它。
