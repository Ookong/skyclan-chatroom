## 一、概念：if 只管晴天（5 分钟）

上节课的年龄闸机有个尴尬：条件不满足时，屏幕一片安静，用户以为程序死了。真实世界要有 B 计划：

- 满了 18 → 欢迎
- 不满 18 → 「再等等，先去看猫武士」

给「否则」留一条路。今天两位新成员：**else** 和 **elif**。

## 二、else：B 计划（8 分钟）

```python
n = int(input("Give me a whole number: "))

if n % 2 == 0:
    print(n, "is even")
else:
    print(n, "is odd")
```

输入 8 → 偶数；输入 7 → 奇数。**必有其一，只走其一。**

else 语法三件事：

- 行尾也要冒号
- 下面的行也要缩进 4 格
- **else 后面不接条件**——if 已经问过了，剩下的全归它

（还记得 `%` 吗？W02-L01 说判断奇偶天天用，兑现了。）

## 三、elif：多岔路口（10 分钟）

只有两条路不够用？**elif** = else + if 合体，读作「否则如果」：

```python
height = int(input("Your height in cm? "))

if height >= 140:
    print("Any roller coaster you like!")
elif height >= 120:
    print("You can ride the small coaster")
else:
    print("Try the carousel first, build some courage")
```

身高 150 → 过山车；125 → 小过山车；100 → 旋转木马。

想再加一条路（比如 160 以上玩跳楼机），中间插一行 elif 就行。路可以有任意多条，但**最多走到一条**。

## 四、分支只走一条（8 分钟）

Python 的走法：**从上往下扫描，命中一条，其余全部跳过。**

用 150 验证：150 >= 140 成立，同时 150 >= 120 也成立，但只打印 "Any roller coaster you like!"——命中第一条后，整串 elif / else 直接跳过，绝不回头。

| 身高 | >= 140？ | >= 120？ | 实际输出 |
|---|---|---|---|
| 150 | 真（命中） | 不再看 | `Any roller coaster you like!` |
| 125 | 假 | 真（命中） | `You can ride the small coaster` |
| 100 | 假 | 假 | 落入 else：`Try the carousel first, build some courage` |

「从上往下、命中即止」是 elif 链的灵魂，也是下面第一个坑的根源。

## 五、⚠️ 新手三大坑（8 分钟）

1. **顺序陷阱**：把 >= 120 的分支放在 >= 140 前面，150 一进门就命中 120，永远坐不上大过山车。规矩：**门槛从高到低排**（大的条件放前面）。
2. **else 后写条件**：`else height < 120:` ❌ SyntaxError。else 是「剩下的全部」，不需要再说条件。
3. **elif 拼错 / 漏冒号**：elif 不是 elseif，更不是 elsif。if / elif / else 行尾的冒号一个不能少。

老规矩：坑 2、坑 3 各故意踩一次，读报错，再修好。
