# W03-L01 · 如果……那么：if + 比较运算符

## 一、概念：程序会看情况办事（5 分钟）

前三周的程序都是"直线剧本"：从第一行演到最后一行，不管不顾。真实世界不是这样——

- 分数到了 60，才能及格
- 猫粮剩得不多，就该提醒囤货
- 边境出现入侵者，族长才下令出击

**if** 就是让程序学会"看情况"。玩 Scratch 的同学：「如果……那么……」积木，一模一样的思想。

## 二、if 的样子（10 分钟）

新建 `first_if.py`，亲手敲（注意冒号和缩进）：

```python
score = int(input("What score did you get? "))

if score >= 60:
    print("Passed!")
    print("You can play Scratch for 30 minutes")
```

运行两次：输入 80，两行都打印；输入 59，一片安静——条件不满足，if 手下的活儿全部跳过。

### 逐字拆解

| 部件 | 作用 |
|---|---|
| `if` | 「如果」这个词 |
| `score >= 60` | 条件：结果非真即假 |
| `:` | 冒号 =「那么」，下面缩进的行归它管 |
| 缩进 4 格 | 手下名单：哪些行听 if 的 |

## 三、比较运算符六兄弟（10 分钟）

| 写法 | 读作 | 例子 | 结果 |
|---|---|---|---|
| `==` | 等于 | `10 == 10` | True |
| `!=` | 不等于 | `"猫" != "狗"` | True |
| `>` | 大于 | `3 > 5` | False |
| `<` | 小于 | `3 < 5` | True |
| `>=` | 大于等于 | `60 >= 60` | True |
| `<=` | 小于等于 | `59 >= 60` | False |

比较的结果是 **True / False**（真 / 假），这类值叫布尔值，今天混个脸熟。

Shell 里试玩（`>>>` 后输入，回车即答）：

```python
>>> print(3 > 5)
>>> print("10" == 10)
>>> print("a" != "b")
```

第二行是 False——类型不同（W02-L01 的知识：字符串 ≠ 数字），Python 眼里永不相等。

## 四、缩进即语法（7 分钟）

别的语言用花括号圈地盘，Python 用**缩进**。看两段程序的差别：

```python
score = 59
if score >= 60:
    print("Passed!")
print("Done!")
```

最后一行**没缩进**，它不属于 if——不管及不及格都会打印。缩进与否，改变行的归属，这就是「缩进即语法」。

Thonny 小贴士：写完 `if ...:` 按回车，光标自动缩进；想退出缩进，按一次删除键。

## 五、⚠️ 新手三大坑（8 分钟）

1. **= 与 == 混淆**：`if age = 18:` → SyntaxError 直接拦下。记牢：一个等号是**装进去**（赋值），两个等号是**比一比**（比较）。Python 帮你把关，感恩。
2. **漏冒号**：`if score >= 60` 忘了 `:` → `SyntaxError: expected ':'`。if 行尾的冒号，一个不能少。
3. **缩进忽长忽短**：一行缩 4 格、下一行缩 3 格 → `IndentationError`。规矩：统一 4 个空格，全文件一致。

老规矩：三个坑各故意踩一次，读报错最后一行，再修好。

## 七、练习答案（先做再看！）

**1.**
```python
score = int(input("What score did you get? "))

if score >= 60:
    print("Passed!")
if score >= 90:
    print("Excellent!")
```
输入 95 打印两行——两个 if 各自独立判断，都会执行；输入 80 只打印第一行。

**2.** True、False、True。中间那题：字符串 "10" 和数字 10 类型不同，不相等。

**3.**
```python
age = int(input("How old are you? "))
if age >= 18:
    print("Enjoy the show!")
```

**4.**
```python
cat_food = 2
if cat_food <= 3:
    print("Cat food is running low - time to stock up")
```

**5.**
```python
secret = "thawpaw"
password = input("Enter the password: ")
if password == secret:
    print("Welcome back, Clan leader")
```
注意是 `==` 不是 `=`。
