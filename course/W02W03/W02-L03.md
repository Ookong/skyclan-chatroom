## 一、概念：拼接到底哪里痛（5 分钟）

W01 我们用 `+` 拼过话，回忆一下痛苦：

```python
print("So happy to meet you, " + name + "! You are " + str(age) + " years old")
```

三大痛点：①引号加号写到眼花 ②数字必须先 str() ③空格标点全靠人肉安排。

本课主角 f-string，一行治百病：

```python
print(f"So happy to meet you, {name}! You are {age} years old")
```

（W01-L03 的计算器见过它一面，今天正式拜师。）

## 二、f-string 三步上手法（8 分钟）

1. 引号前写一个 `f`
2. 变量名放进花括号 `{}`
3. 打印时自动填空，数字也**自动变文字**

### 逐字拆解 `f"Next year you will be {age + 1}"`

| 部件 | 作用 |
|---|---|
| `f` | 开关：开启"自动填空"模式 |
| `"..."` | 还是老字符串，引号照旧 |
| `{age + 1}` | 花括号里的内容**先算好**，结果填进去 |

```python
age = 12
print(f"Next year you will be {age + 1}")
```

输出：`Next year you will be 12`。

## 三、花括号 = 小型计算器（8 分钟）

花括号里能放的不止变量，**算式也行**：

```python
name = "Fireheart"
price = 39.5
count = 3

print(f"{name} bought {count} bags of cat food")
print(f"Total: {price * count} yuan")
print(f"{name.upper()} roars!")
print(f"The name has {len(name)} letters")
```

花括号里算完，结果自动变文字填进去——str() 都省了。上节课的字符串功夫，全部可以在花括号里出招。

## 四、格式化魔法（10 分钟）

花括号里加个冒号，还能规定数字的**出场造型**。

**:.2f —— 固定两位小数**（治 0.1 + 0.2 的零头病）：

```python
print(f"{0.1 + 0.2}")
print(f"{0.1 + 0.2:.2f}")
```

第一行 `0.30000000000000004`，第二行干干净净 `0.30`。算钱必用。

**:, —— 千位分隔**（大数美容）：

```python
money = 1234567.891
print(f"{money:,.2f}")
```

输出 `1,234,567.89`。Tree 看营业额、ThawPaw 看游戏金币，都用得上。

**对齐 —— 居中 :^ 、右对齐 :>**：

```python
a = "Firestar"
b = "Leader"
print(f"{a:^12}")
print(f"{b:^12}")
print(f"{1234567:>12}")
```

`:^12` 站进 12 格宽的空间正中间，`:>12` 靠右站。做牌匾、做小票、对表格，瞬间专业。

## 五、什么时候不用 f-string（4 分钟）

f-string 好用，但不是处处必须：

- 只打印一个变量：`print(name)` 更省事
- 纯固定文字：普通字符串就好，别加 f
- 花括号本身想出现在文字里：得写 `{{}}` 转义，麻烦——这时普通字符串反而清爽

工具选顺手的，不炫技。

## 六、⚠️ 新手三大坑（8 分钟）

1. **忘写 f**（最阴险，不报错）：`print("{name} hello")` 原样照念花括号。输出不对，先查 f！
2. **同款引号打架**：`f"I said "{word}""` ❌。解法：内外用不同引号，`f'I said "{word}"'`（单引号双引号在 Python 里等效，随手换）
3. **想打印字面花括号**：f-string 里 `{` 是特殊记号，想让它出现得写两遍——`print(f"{{effort}}")` 输出 `{effort}`
