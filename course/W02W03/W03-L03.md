## 一、概念：复杂世界需要组合条件（5 分钟）

单一条件不够用了：

- 当上战士：要「满 12 个月**且**训练完成」——缺一不可
- 周末：是「周六**或**周日」——满足其一
- 不饿：not 饿

三个连接词：**and（且）、or（或）、not（非）**。Scratch 同学：就是运算积木里的「…与…」「…或…」「并非…」。

## 二、and：两个都要真（8 分钟）

```python
age = int(input("How many months old is this cat? "))
trained = input("Finished all training? (yes / no) ")

if age >= 12 and trained == "yes":
    print("Warrior name granted!")
```

输入 13 和 yes → 授予；13 和 no → 安静；5 和 yes → 安静。**and 左右都真，整体才真**，一假全假。

## 三、or：一个真就真（7 分钟）

```python
day = input("What day is it today? ")

if day == "Saturday" or day == "Sunday":
    print("Family coding time!")
```

周六 ✅，周日 ✅，周一 ❌。**or 左右至少一个真，整体就真**，全假才假。

## 四、not：反着说（5 分钟）

```python
hungry = True
print(not hungry)
```

输出 `False`。not 把真假对调。用得不多，但读别人代码常见，认得即可。

新手期大法：**给组合条件套小括号**，`(age >= 12) and (trained == "yes")`，谁先谁后一目了然，不怕记错优先级。

## 五、实战：成绩等级评定器（12 分钟）

需求：输入成绩（0-100）和出勤（0-20 次），规则：

- 成绩 >= 90 **且** 出勤 >= 16：A+
- 成绩 >= 80 **且** 出勤 >= 14：A
- 成绩 >= 60 **且** 出勤 >= 10：B
- 其余：C

新建 `grader.py`：

```python
print("=== Grade Judge ===")

score = int(input("Test score (0-100): "))
attend = int(input("Attendance (0-20): "))

if score >= 90 and attend >= 16:
    grade = "A+"
elif score >= 80 and attend >= 14:
    grade = "A"
elif score >= 60 and attend >= 10:
    grade = "B"
else:
    grade = "C"

print(f"Result: {grade}")
```

看两点：

1. elif 链从上往下、命中即止（上节课的灵魂）——进了 A+ 就不会再看 A
2. 每个条件都是 and 组出的两个维度：分数再高，翘课多了照样掉级

**规则是活的**：改成三科成绩？加一条努力分？随意。改完至少测四组数据：95/20、95/10、82/15、59/20，先笔算等级再运行。

## 六、⚠️ 新手三大坑（7 分钟）

1. **用 or 表达「中间范围」翻车**：`if score > 60 or score < 90:` 永远为真——任何数都至少满足一头。夹在中间要用 and：`score > 60 and score < 90`。
2. **字符串比大小**：`"9" > "10"` 居然是 True！字符串按字典序逐字比（'9' 排在 '1' 后面）。要比数值，先 int——W02-L01 的老朋友。
3. **括号里的等号**：套小括号是好习惯，但别把 `==` 手滑写成 `=`（W03-L01 的坑穿越而来）。
