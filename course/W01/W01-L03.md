## 一、概念：让程序跟你聊天（5 分钟）

目前为止都是程序单方面打印。加上 `input`，程序就能**提问并记住你的回答**：

```python
name = input("What is your name? ")
```

拆解：
- 先打印括号里的问题
- 然后**程序停下，等你打字**，你按回车
- 你打的字就变成了结果，被装进 `name` 盒子

## 二、第一个对话程序（10 分钟）

新建 `W01-L03-practice.py`（放 `~/learning-homework/<你的学员名>/homework/`，和作业同目录）：

```python
print("Hello! I am the quiz bot")

name = input("What is your name? ")

game = input("What game do you like best? ")

```

运行，认真回答三个问题，看程序的回应。

### 拆解拼接

`"So happy to meet you, " + name + "!"` —— `+` 把字符串首尾粘起来：
- 引号里是固定文字，`name` 是盒子里的内容
- 空格标点要自己设计在引号里（`" likes "` 前后有空格）
- `+` 只能连接字符串，连数字会报错——马上讲

## 三、致命细节：input 收到的永远是文字（10 分钟）

`input` 哪怕收到数字，也当作**字符串**处理：

```python
age = input("How old are you? ")
print(age + 1)        # error!
```

报错：字符串不能加数字。你说"11"，程序看做两个字符「1」「1」。

解法——**转换**：

```python
age = int(input("How old are you? "))
print(age + 1)        # works!
```

`int(...)` 把"11"变成 11（真数字）。int 就是 integer（整数）的缩写——顾名思义，它的工作就是把"文字数字"变回整数。

口诀：**input 收到的是话，要算数先 int。**

再体验一次两种东西的差别：

```python
print("2026" + "2026")    # 20262026 (concatenation)
print(2026 + 2026)        # 4052 (math)
```

## 四、实战：四则计算器（10 分钟）

新建 `calculator.py`（同目录），亲手敲：

```python
print("=== Family Calculator ===")

a = float(input("First number: "))
b = float(input("Second number: "))

print(f"{a} + {b} = {a + b}")
print(f"{a} - {b} = {a - b}")
print(f"{a} * {b} = {a * b}")
print(f"{a} / {b} = {a / b}")
```

运行，输入 12 和 3，检查四行结果。

### 新面孔：f-string（W02 详细讲，今天混个脸熟）

`print(f"{a} + {b} = {a + b}")` —— 引号前加 `f`，花括号 `{}` 里的变量和算式会**自动算好填进去**。比 `+` 拼接舒服得多，W02-L03 专门教。

### ⚠️ 留一个Bug当作业

试输入第二个数 0？会看到 `ZeroDivisionError`（除零错误）。
**别修它**——记住这个名字，第 4 周「异常处理」课我们正式收拾它。好课程会埋伏笔。
