# W01-L02 · 变量（variable）：给东西起名字

> 用时：35-45 分钟 · 难度：⭐⭐ · 核心概念：变量（variable）、赋值（assignment）、新手第一大坑

---

## 一、概念：变量 = 贴了标签的盒子（5 分钟）

**变量**（variable）就是给数据起个名字，以后用名字就能拿到数据。

```python
score = 95
```

读作：准备一个盒子，贴上 `score` 标签，里面装 95。

- `=` 读作"**装进去**"，英文叫 **assignment（赋值）**——它不是数学的 equals（等于）！
- 标签名（变量名）自己起，要见名知意
- 盒子里的东西随时可以换

为什么需要变量：程序里同一份数据要用很多次（比如游戏里的得分），不可能每次都重写一遍——起个名字，一劳永逸。

## 二、第一批变量（10 分钟）

新建文件 `W01-L02-practice.py`（Thonny 里 `文件 → 新建`），保存到自己的练习目录 `~/learning-homework/<你的学员名>/homework/`（以 ThawPaw 为例：`thawpaw/homework/`，Tree 对应 `tree/homework/`；没有就新建，平铺不建周子目录），亲手敲：

```python
name = "Alex"
age = 12
pet = "cat"
score = 95

print(name)
print(age)
print(pet)
print(score)
```

Run 运行，四行数据都出来了。

### 拆解

- `name = "Alex"` —— 文字要引号（字符串）
- `age = 12` —— 数字**不要**引号
- `print(name)` —— 打印盒子里的**内容**：Alex

### 换盒子里的东西

在文件末尾加：

```python
score = 95
print(score)
score = 100
print(score)
```

第一次打印 95，改完再打印变 100。旧值被扔掉，盒子里永远是最新装的。

### 最烧脑的一行：`score = score + 5`

```python
score = 90
score = score + 5
print(score)      # 95
```

读三遍："**新的** score = **旧的** score + 5"。
执行顺序：① 打开盒子拿出 90 → ② 算 90 + 5 得 95 → ③ 把 95 装回盒子。
（玩过 Scratch 的同学：这就是「将得分增加 5」积木。）

## 三、新手第一大坑（10 分钟）

这两行**各跑一次**，看差别：

```python
print(name)      # prints: Alex (open the box)
print("name")    # prints: name (read the label as-is)
```

一句话记住：**带引号 = 原样照念，不带引号 = 打开盒子拿内容。**

再用数字验证一遍坑的威力：

```python
age = 12
print("age")     # prints: age
print(age)       # prints: 12
```

这个坑至少会陪伴你前两周，每次 print 输出不对，先检查引号。

## 四、变量命名规则（5 分钟）

- ✅ 合法：`score`、`my_name`、`pet2`、`love_cats`
- ❌ 不合法：`2score`（数字开头）、`my name`（有空格）、`print`（占用命令名）
- 习惯：全小写 + 下划线；名字要有含义——`cat_age` 比 `x` 好一万倍

## 五、新装备：备注（comment）——写给看代码的人（3 分钟）

程序里常常要留话——给看代码的人看，不让电脑执行。这就是**备注**（comment）：

```python
# this whole line is a comment - the computer skips it
score = 95   # a comment can also follow the code, like this
```

- `#` 号开头，到行尾为止都是备注，电脑看都不看
- 用处一：**给代码写说明**——给读代码的人，包括三个月后的自己
- 用处二：**给文件分区**——做练习时每道题前写一行 `# --- 题 1 ---`，导师一眼看清你做到了第几题
- 习惯：备注说「为什么」就够，不用复述代码本身

## 七、练习答案（先做再看！）

**1.**
```python
my_name = "ThawPaw"
my_hobby = "playing Snake"
my_dream = "build my own game"
my_food = "ice cream"
print(my_name)
print(my_hobby)
print(my_dream)
print(my_food)
```

**2.** `print(food)` → ice cream；`print("food")` → food。前者开盒子，后者照念。

**3.** 0 → 10 → 30。你若猜 0/10/50，说明把 `* 3` 当成了 `+ 20`；猜错不丢人，回看「最烧脑的一行」。

**4.**
```python
pet_name = "Snowball"
pet_type = "cat"
pet_age = 2
print("Name:", pet_name)
print("Type:", pet_type)
print("Age:", pet_age)
```

**5.**
```python
left = "meow"
right = "woof"
print(left, "and", right, "are friends")
```
逗号分隔的内容之间会自动加空格。（另一种解法 W02 的 `+` 拼接和 f-string 都能做，学到再回来看。）
