# W01-L02 · 变量：给东西起名字

> 用时：35-45 分钟 · 难度：⭐⭐ · 核心概念：变量、赋值、新手第一大坑

---

## 一、概念：变量 = 贴了标签的盒子（5 分钟）

**变量**就是给数据起个名字，以后用名字就能拿到数据。

```python
score = 95
```

读作：准备一个盒子，贴上 `score` 标签，里面装 95。

- `=` 读作"**装进去**"，不是数学的等于！
- 标签名（变量名）自己起，要见名知意
- 盒子里的东西随时可以换

为什么需要变量：程序里同一份数据要用很多次（比如游戏里的得分），不可能每次都重写一遍——起个名字，一劳永逸。

## 二、第一批变量（10 分钟）

新建文件 `my_vars.py`（Thonny 里 `文件 → 新建`），亲手敲：

```python
name = "小明"
age = 11
pet = "猫"
score = 95

print(name)
print(age)
print(pet)
print(score)
```

Run 运行，四行数据都出来了。

### 拆解

- `name = "小明"` —— 文字要引号（字符串）
- `age = 11` —— 数字**不要**引号
- `print(name)` —— 打印盒子里的**内容**：小明

### 换盒子里的东西

在文件末尾加：

```python
score = 95
print(score)
score = 100
print(score)
```

第一次打印 95，改完再打印变 100。旧值被扔掉，盒子里永远是最新装的。

### 最烧脑的一行：`score = score + 5`

```python
score = 90
score = score + 5
print(score)      # 95
```

读三遍："**新的** score = **旧的** score + 5"。
执行顺序：① 打开盒子拿出 90 → ② 算 90 + 5 得 95 → ③ 把 95 装回盒子。
（玩过 Scratch 的同学：这就是「将得分增加 5」积木。）

## 三、新手第一大坑（10 分钟）

这两行**各跑一次**，看差别：

```python
print(name)      # 输出：小明（打开盒子拿内容）
print("name")    # 输出：name（原样照念四个字母）
```

一句话记住：**带引号 = 原样照念，不带引号 = 打开盒子拿内容。**

再用数字验证一遍坑的威力：

```python
age = 11
print("age")     # 输出：age
print(age)       # 输出：11
```

这个坑至少会陪伴你前两周，每次 print 输出不对，先检查引号。

## 四、变量命名规则（5 分钟）

- ✅ 合法：`score`、`my_name`、`pet2`、`love_cats`
- ❌ 不合法：`2score`（数字开头）、`my name`（有空格）、`print`（占用命令名）
- 习惯：全小写 + 下划线；名字要有含义——`cat_age` 比 `x` 好一万倍

## 五、动手练习（先做完，再看第六节答案）

1. 建 4 个变量：`my_name` / `my_age` / `my_hobby` / `my_dream`，全部打印
2. 大坑验证：建 `food = "冰淇淋"`，分别跑 `print(food)` 和 `print("food")`，把两个输出各是什么写进注释
3. 先猜再跑：`score = 0` → 打印 → `score = score + 10` → 打印 → `score = score * 3` → 打印。运行前先在纸上写下三次输出，对了才算真懂
4. 宠物信息卡：`pet_name` / `pet_type` / `pet_age` 三个变量，打印成三行名片
5. 🚀 加速挑战：`left = "喵"`、`right = "汪"`，只允许用变量名（不许直接写喵和汪），打印出「喵和汪是朋友」（提示：print 里可以用逗号隔开多个东西）

## 六、练习答案（先做再看！）

**1.**
```python
my_name = "猴哥"
my_age = 40
my_hobby = "看分身干活"
my_dream = "2030 打败 Nielsen IQ"
print(my_name)
print(my_age)
print(my_hobby)
print(my_dream)
```

**2.** `print(food)` → 冰淇淋；`print("food")` → food。前者开盒子，后者照念。

**3.** 0 → 10 → 30。你若猜 0/10/50，说明把 `* 3` 当成了 `+ 20`；猜错不丢人，回看「最烧脑的一行」。

**4.**
```python
pet_name = "雪球"
pet_type = "白猫"
pet_age = 2
print("名字：", pet_name)
print("种类：", pet_type)
print("年龄：", pet_age)
```

**5.**
```python
left = "喵"
right = "汪"
print(left, "和", right, "是朋友")
```
逗号分隔的内容之间会自动加空格。（另一种解法 W02 的 `+` 拼接和 f-string 都能做，学到再回来看。）
