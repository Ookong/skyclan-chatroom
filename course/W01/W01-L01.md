# W01-L01 · 认识终端 + 装 Thonny + 第一行代码

> 用时：35-45 分钟 · 难度：⭐ · 无需任何基础

---

## 一、Python 是什么（5 分钟）

Python 是全世界最流行的编程语言之一：AI、游戏、科学计算、网站都在用。
写 Python = 用它能看懂的文字，一步一步告诉电脑做什么。

**给玩过 Scratch 的同学：** Python 就是"文字版 Scratch"，你搭积木做的贪吃蛇，思想完全通用，只是把拖积木变成打字。
**没玩过 Scratch 也不用管上面这句**，直接开始。

本课两大任务：① 装好写代码的工具 Thonny；② 写出你的第一行代码。

## 二、先见见终端（5 分钟，认个脸就行）

Mac 上按 `Command + 空格`，输入 `终端` 或 `Terminal`，回车。看到一个窗口，里面有一行 `xxx %` ——这叫**提示符**，意思是"轮到你打字了"。

逐条试试（每条后回车）：

```bash
pwd           # where am I
ls            # what files are here
echo "hello"   # say it back
```

### 命令记忆小表格

这些命令都是英文缩写，认了全称就不需要死记：

| 命令 | 英文全称 | 一句话记忆 |
|---|---|---|
| `pwd` | **p**rint **w**orking **d**irectory（打印工作目录） | 我在哪个目录 |
| `ls` | **l**i**s**t（列出） | 这里有什么文件 |
| `cd` | **c**hange **d**irectory（切换目录） | 去别的目录 |

> `cd` 今天先混个脸熟，第 7 周 git 课会天天用它。

看完可以关掉它。今天只需要知道：**终端 = 用打字而不是鼠标指挥电脑**。程序员和 AI 分身们天天用它，我们第 7 周（git 课）会正式回来。

## 三、安装 Thonny（5 分钟）

Thonny 是专门为初学者设计的 Python 编辑器，界面极简：

1. 浏览器打开 [thonny.org](https://thonny.org)
2. 点右上 **Download** → 选 **Mac** 版
3. 打开下载的 dmg，把 Thonny 拖进"应用程序"
4. 打开 Thonny

界面只有三处重要：
- **上方大空白区**：写代码的地方（叫编辑器）
- **下方 Shell 区**：立刻试一行代码的地方（问一句答一句）
- **绿色圆点 Run 按钮**：运行整个程序（相当于游戏的开局按钮）

## 四、第一行代码（15 分钟）

在上方空白区**亲手打字**（不要复制粘贴！从今天起 4 周内全部手敲）：

```python
print("Hello, Python!")
print("This is my first line of code")
```

点 Run，第一次会让你保存，文件名填 `first.py`。看下方 Shell 区——你的程序说话了！🎉

### 逐字拆解 `print("Hello, Python!")`

| 部件 | 作用 |
|---|---|
| `print` | 命令名：把内容打印出来（Python 自带） |
| `(` `)` | 内容放括号里，交给命令 |
| `"Hello, Python!"` | 引号包住的一串文字，叫**字符串** |

规则：一行一个命令，结尾不用分号。

### ⚠️ 新手三大坑（每个都值得亲手踩一次）

1. **引号必须英文**：`"..."` ✅，中文引号 `“...”` ❌（输入法切英文！）
2. **引号要一对**：`print("你好)` 少右引号 → 报错
3. **区分大小写**：`Print` ≠ `print`

踩坑方法：故意删掉一个引号，点 Run，读报错。**报错最后一行永远是最重要的信息。** 读完把引号补回来。

## 五、Shell 秒答区（5 分钟）

点一下下方 Shell 区域，直接输入（`>>>` 后面）：

```python
>>> 2 + 2
>>> 100 * 7
>>> "meow" * 10
```

回车即答。`"meow" * 10` 会发生什么？亲手试。（字符串乘数字 = 重复！）

## 六、动手练习（先做完，再看第七节答案）

1. 打印三行自我介绍：昵称（化名，比如 ThawPaw）/ 最喜欢的游戏 / 最想学会的一件事
2. 用 print 打一只 ASCII 猫：

```python
print(" /\_/\ ")
print("( o.o )")
print(" > ^ < ")
```

3. 在 Shell 里算：11 年大约是多少天（11 × 365）？再想想：为什么只能说「大约」？
4. 故意制造一次报错（删引号或改大写 P），抄下报错最后一行，再修好
5. 🚀 加速挑战：用 print 打出一个 5 行以上的图案（房子、旗子、爱心都行）

## 七、练习答案（先做再看！）

**1.** 三行 print，引号包住文字即可。参考：
```python
print("Hi, I am ThawPaw")
print("My favorite game is Snake")
print("I want to build my own game")
```

**2.** 照抄运行即可，注意每行引号都要配对。

**3.** Shell 里输入 `11 * 365` 得 4015（数字不要引号！加了引号会变成重复 365 遍）。追问答案：因为闰年——每四年多一天，一年平均约 365.25 天，所以 ×365 只是粗算。

**4.** 删引号会看到 `SyntaxError: unterminated string literal`（语法错误：字符串没写完）；`Print` 大写会看到 `NameError: name 'Print' is not defined`（没有叫 Print 的命令）。**NameError 和 SyntaxError 以后会天天见，混个脸熟。**

**5.** 自由发挥，5 行以上 print 就算过。两个都试过的同学：注意 `"   *"` 里空格也是字符串的一部分，可以用来对齐图案。
